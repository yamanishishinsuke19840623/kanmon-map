データを使う

かんもんノートが取材した下関・門司の722か所を、だれでも使えるデータとして公開しています。学校のまち学習、観光案内、地域の調べもの、アプリづくりなどにご利用ください。

ダウンロード

  • 取材先一覧.csv（Excelでそのまま開けます）
  • 取材先一覧.geojson（地図ソフト・GIS向け）

更新日：2026-10-30 ／ 収録 722件。記事が増えると更新します。

利用条件

データベースは Open Database License（ODbL 1.0） で提供します。営利・非営利を問わず利用・加工・再配布できます。利用するときは次の出典を表示し、加工したデータを公開する場合は同じ条件で公開してください。

かんもんノート取材先データ（https://map.kanmonnote.com/）/ © OpenStreetMap contributors / 「アドレス・ベース・レジストリ」（デジタル庁）を加工 / 「位置参照情報」（国土交通省）を加工

位置のうち、OpenStreetMapと照合したものはOSM由来（ODbL 1.0）です。記事の住所から求めたものは、デジタル庁「アドレス・ベース・レジストリ」（利用規約、公共データ利用規約1.0）で号（建物）・地番の単位に、または国土交通省「位置参照情報」（利用約款）で街区の単位に変換して加工したものです。地番の位置は、デジタル庁が「登記所備付地図データ」（法務省）を基に整備した地番マスター位置参照によります。記事本文・写真はこのデータに含まれません（元記事の著作物です）。

項目

項目内容
id記事ID（WordPress）
title / url / date記事の題名・URL・掲載日
place / address取材先の名前・記事に書かれた住所
town / area住所から分類した町名・エリア
categoryジャンル（自動分類を含む）
closedInArticle記事に閉店・終了の記載があれば true
lat / lon緯度・経度（世界測地系）
locationMethod / locationAccuracy位置の求め方と精度
locationSource / locationLicense位置の根拠と、その出典の条件

注意

  • 全取材記事の網羅ではありません。OSMの施設と照合できた記事と、記事の住所から位置を求められた記事のみです。
  • 営業・移転・閉店の現状は保証しません。記事掲載時点の情報です。
  • 記事の住所から求めた地点は、デジタル庁「アドレス・ベース・レジストリ」の号（建物）・地番の代表点、または国土交通省「位置参照情報」の街区の代表点で、入口の位置ではありません。
  • Google Mapsの埋込座標はこのデータへ転用していません。
  • 経路案内・測量・営業状況の確認には使えません。

データの誤り・閉店や移転の情報は、取材先の今を知らせるからお知らせください。
